# agent-sudo 1.0.1 — public installation validation

Date: 2026-11-02. The exact production binaries passed 254 installed-binary checks before publication. A separate public installation run then passed **38 checks**, 19 per VM.

The literal live-page command was executed in a real terminal in both disposable Ubuntu VMs:

```sh
curl -fsSL https://tools.simplehelp.io/agent-sudo/install.sh | sh
```

Normal sudo password authentication succeeds while the script arrives through a pipe, without recipient selection. Tests install and reinstall machine-wide from actual public HTTPS URLs, verify installed binary hashes, grant/run/status/revoke for two recipients, and exercise the new creator-scoped `agent-sudo revoke all` across two recipients. Removal succeeds afterward.

Platforms: Ubuntu 24.04.5 LTS amd64 / sudo 1.9.15p5, and Ubuntu 26.04.1 LTS amd64 / sudo-rs 0.2.13. Full package/kernel versions and broader attack tests are recorded in 1.0.1-VALIDATION.md.

VM-local PATH shims inject failed/truncated bootstrap and package downloads, checksum mismatches and unsupported platforms. They preserve the existing installed binary/configuration/policy hashes and never reach sudo. Every one of the 2564 proper bootstrap byte prefixes was tested with command markers, with the full script as a positive control; none begins installation. These are deliberate fault fixtures, not live hosting outages. The short shell pipeline can return zero when curl fails before producing script bytes; curl emits the error and nothing is installed. Confirm the final installation message/version.
